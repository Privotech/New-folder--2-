# PrivoKeep 🚀

A modern, full-featured personal productivity workspace combining Google Keep-style cards with a comprehensive Task Management board. Built with **Next.js 15 (App Router)**, **TypeScript**, and **Tailwind CSS**.

## ✨ Features

### 📝 Notes & Stacks (PrivoKeep)
- **Google Keep-style Cards**: Color palettes (yellow, blue, green, pink, purple, default), pin badges, and responsive grid layout.
- **Rich Tagging & Categories**: Organize by Personal, Work, Ideas, or Research.
- **Priority Flags**: Low, Medium, High, and Urgent priority flags.
- **Stacks Management**: Group notes into collapsible, pinnable Stacks with live note counters.
- **Image Attachments**: Attach photos to notes with built-in instant preview.
- **Search & Filters**: Instant full-text search across titles, content, tags, and colors.
- **Share & Export**: Share notes via link, clipboard, or JSON export.

### ✅ Task Board (TodoApp)
- **Task Management**: Create tasks with descriptions, priority levels, categories, and due dates.
- **Subtasks Hierarchy**: Checkable subtasks with live progress tracking.
- **Live Stats Dashboard**: Total tasks, completed, pending, completion rate progress ring, and due today indicators.
- **Bulk Operations**: Multi-select tasks to mark complete or delete in batch.
- **Sorting & Filtering**: Filter by Active, Completed, Priority, and Category with customizable sort orders.

### 🎨 Design & Experience
- **Dark Mode & Light Mode**: Complete dark/light theme toggle.
- **Responsive Layout**: Optimized for both mobile devices and desktop screens.
- **Offline & Instant Data**: Fast client-side storage persistence with seed data.

## 🛠 Tech Stack

- **Framework**: Next.js 15 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Runtime**: Node.js 22
